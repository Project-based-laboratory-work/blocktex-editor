# image_ai — 画像読み込みの自作AI（通し）

画像（スクリーンショット）→ ラベル付きIR を、自作AIをつないで作る。チームの評価（[evaluation](../evaluation/README.md)）に
`image_ai` として登録している。

```
画像 ─ 座標AI（image_layout）─→ ブロックの四角とラベル
     ─ EasyOCR ─────────────→ 文字の行 ─ 中心が入るブロックへ振り分け
                                          ├ table → 表AI（image_table）: セル・罫線・揃え
                                          ├ math  → 数式AI（math_ocr）: 1行ずつに切って LaTeX（align* の & を付ける）
                                          ├ code  → 行の左端のずれから字下げ
                                          └ それ以外 → 行を上から順につなぐ
     ─ 読み順（2段組なら左の段 → 右の段）─→ ラベル付きIR
```

- 座標AIが見落とした行は、近い行どうしをまとめて段落にする
- ページの上端・下端の帯（ヘッダー・ページ番号の置き場所）の、本文より大きくない1行のブロックは other にする。
  座標AIは数字だけのページ番号を数式と間違えやすいため。帯の幅は、学習側の image_dataset と評価用データの両方で
  見出し・タイトルにかからない位置（上 12.5%、下 10%）

## 使い方

`ai/` で実行する。EasyOCR と、各モデルの重み（`image_layout/checkpoints/unet/`・`image_table/checkpoints/split/`・
`math_ocr/checkpoints/v4_im2latex/`。数式の重みはリリース `math-ocr-v4` にもある）が要る。

```bash
python -m image_ai.pipeline <画像> -o out.labeled.json
python -m evaluation.make_dataset --out evaluation/data/synth_all --docs 40 --features all
python -m evaluation.run --model image_ai --dataset evaluation/data/synth_all
python -m pytest image_ai/tests
```

## 結果（evaluation/data/synth_all、40文書。ページを 200dpi の画像にして読む）

| 指標 | EasyOCR＋ルールベース | **image_ai** |
|---|---|---|
| ブロックの検出 F1 | 0.733 | **0.864** |
| ラベルの正解率 | 0.568 | **0.952** |
| 読み順 | 0.961 | **0.981** |
| コードの字下げ | 0.400 | **0.790** |
| 表の形 / セルの文字 | − | 0.950 / 0.785 |
| 数式のトークン誤り率 | − | 0.076 |
| 文字の誤り率（CER） | **0.124** | 0.142 |
| 枠の位置の正確さ（mIoU） | **0.816** | 0.720 |

ラベルごとの F1（image_ai）: タイトル 1.000・キャプション 0.972・見出し 0.964・表 0.952・箇条書き 0.942・日付 0.851・
図 0.824・コード 0.732・数式 0.710・段落 0.695・著者 0.667・ページ番号など 0.480

工夫ごとの効果（ブロックの検出 F1 / ラベルの正解率）:

| | F1 | ラベル | 数式の誤り率 | 図 F1 | ページ番号など F1 |
|---|---|---|---|---|---|
| つないだだけ | 0.866 | 0.932 | 0.415 | 0.417 | 0.000 |
| ＋見落とした行を拾う・複数行の数式・帯の中は other | 0.877 | 0.953 | 0.082 | 0.417 | 0.593 |
| ＋座標AIの学習で図を水増し（今の既定） | 0.864 | 0.952 | 0.076 | **0.824** | 0.480 |

- 図の水増し（image_layout/figures.py）: 学習データの図が中身の無い枠だけで、棒グラフの図を見つけられなかった。
  図は倍になったが、段落（0.740 → 0.695）と数式（0.863 → 0.710。数式でないものを数式と言う）が下がった。
  本物のレポートの図はグラフや写真なので、水増しした方を既定にした
- 文字の誤り率と枠の位置の正確さは、OCRの行の枠をそのまま使うルールベースの方が良い
- 時間は image_ai が 1.7 秒/ページ（GPU）、ルールベースが 22.8 秒/ページ（CPU）。条件が違うので比べられない
- 評価用データは TeX で組んだ文書をきれいに画像にしたもの。本物のスクショでの確認はこれから
