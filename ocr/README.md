# OCR精度比較プロジェクト

## 1. 概要

本プロジェクトでは、OCR（光学文字認識）を用いて画像内の文字をテキストデータに変換し、認識結果や精度を比較・検証する。

複数のOCRエンジンを使用し、同じ入力データに対する認識結果を比較することで、それぞれの特徴や課題を確認する。

## 2. 使用するOCRエンジン

本プロジェクトでは、以下のOCRエンジンを使用する。

- **EasyOCR**：担当メンバーがPythonから利用し、画像の文字認識と結果の分析を行う。
- **Tesseract**：担当メンバーが利用し、画像の文字認識と結果の分析を行う。

各OCRエンジンの実装は分けつつ、入力データや評価方法を可能な限り統一し、公平に比較できるようにする。

## 3. 開発環境

- Python
- Git / GitHub
- 各OCRエンジンに必要なライブラリ・ソフトウェア

使用するライブラリやバージョンなどの詳細は、各実装の設定ファイルで管理する。

## 4. 評価方法

同じ入力データに対して各OCRエンジンを実行し、認識結果を比較する。

評価では、以下の観点を確認する。

- 文字の認識精度
- 誤認識や認識漏れの有無
- 文字以外の不要な検出
- 処理時間

必要に応じて、正解テキストと認識結果を比較し、定量的な評価を行う。

## 5. 出力データ

認識結果は、後から確認・比較できる形式で保存する。

EasyOCRでは、認識した文字列、信頼度、文字領域の座標などをJSON形式で保存する。

Tesseract側の出力形式については、実装に応じて整理し、比較に必要な情報を取り出せるようにする。

## 6. ディレクトリ構成

各OCRエンジンの実装や出力データは、必要に応じて分けて管理する。

